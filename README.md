# DIVORE | سیستم مدیریت فروشگاه

نرم‌افزار مستقل و کاملاً فارسی (RTL، تقویم شمسی، تومان) برای مدیریت محصولات، انبار، مشتریان، فاکتور فروش و گزارش‌ها.
بدون سرور و بدون Backend؛ همهٔ اطلاعات داخل مرورگر و در IndexedDB ذخیره می‌شود.

## امکانات
- داشبورد با ۹ کارت آماری، نمودار فروش و سود، پرفروش‌ترین‌ها، هشدار موجودی (همه از داده‌های واقعی)
- محصولات: جدول قابل مرتب‌سازی، جستجو و فیلتر، سود خودکار، کد خودکار `DV-001`، بایگانی هوشمند، دسته‌بندی و برند
- انبار: ورود، خروج، اصلاح موجودی و تاریخچهٔ کامل تراکنش‌ها (هیچ تغییری بدون تراکنش ثبت نمی‌شود)
- فاکتور: چند محصول، تخفیف ردیف و کلی، ارزش افزوده، پرداخت کامل/ناقص/نشده، شماره‌گذاری خودکار `INV-000001`
- ثبت اتمیک فاکتور و موجودی (ذخیره، ویرایش با محاسبهٔ اختلاف، ابطال با بازگشت موجودی، محافظت در برابر کلیک چندباره)
- سود واقعی بر پایهٔ قیمت خریدِ ثبت‌شده در لحظهٔ فروش (تغییر بعدی قیمت، فاکتورهای قبلی را تغییر نمی‌دهد)
- خروجی فاکتور بر پایهٔ قالب `reference/faktor-2.xlsx`: چاپ، PDF، PNG، JPG با لوگوی DIVORE
- گزارش‌ها: فروش و سود روزانه/ماهانه، محصولات، ارزش انبار، بدهی مشتریان، وضعیت پرداخت، با بازهٔ زمانی دلخواه
- پشتیبان‌گیری و بازیابی JSON با اعتبارسنجی، حالت روشن/تاریک، PWA و آفلاین

## تکنولوژی‌ها
HTML5، CSS3، JavaScript خالص، IndexedDB، Service Worker، Web App Manifest. هیچ کتابخانهٔ خارجی لازم نیست
(نمودارها SVG محلی‌اند؛ PDF/PNG/JPG با Canvas و یک نویسندهٔ PDF داخلی ساخته می‌شوند).

## فونت
برای بهترین ظاهر، فایل‌های `Vazirmatn-Regular.woff2` و `Vazirmatn-Bold.woff2` را در `assets/fonts/` قرار دهید
(<https://github.com/rastikerdar/vazirmatn>). بدون آن‌ها از فونت‌های فارسی سیستم استفاده می‌شود.
اگر فونت را اضافه کردید، در `sw.js` مقدار `VERSION` را عوض کنید تا کش به‌روز شود.

## اجرای محلی
Service Worker و IndexedDB نیاز به آدرس http دارند (نه باز کردن مستقیم فایل):
```
cd DIVORE
python3 -m http.server 8000
```
سپس `http://localhost:8000` را باز کنید.

## انتشار روی GitHub Pages
1. محتوای همین پوشه را در ریشهٔ یک Repository قرار دهید.
2. Settings ← Pages ← Source: `Deploy from a branch` ← شاخهٔ `main` و پوشهٔ `/ (root)`.
3. بعد از چند دقیقه آدرس `https://USERNAME.github.io/REPO/` فعال می‌شود. همهٔ مسیرها نسبی‌اند.

نکته: پس از هر به‌روزرسانی فایل‌ها، مقدار `VERSION` در `sw.js` را تغییر دهید.

## نحوهٔ استفاده
1. در «تنظیمات» نام فروشگاه، نشانی، شماره اقتصادی و شناسه ملی را وارد کنید (در فاکتور چاپ می‌شوند).
2. در اولین اجرا چند محصول نمونه ساخته می‌شود؛ با «تنظیمات ← حذف داده‌های نمونه» پاک می‌شوند.
3. محصولات را اضافه کنید، موجودی را از «انبار» وارد کنید و از «فاکتورها ← فاکتور جدید» بفروشید.
4. تاریخ‌ها را به صورت شمسی `۱۴۰۵/۰۸/۲۹` وارد کنید.

## پشتیبان‌گیری و بازیابی
- «تنظیمات ← پشتیبان‌گیری از اطلاعات»: فایلی مثل `DIVORE-backup-1405-08-29.json` ذخیره می‌شود.
- «بازیابی اطلاعات»: فایل را انتخاب کنید؛ پس از اعتبارسنجی و تأیید، اطلاعات فعلی کاملاً جایگزین می‌شود (از ورود داده تکراری جلوگیری می‌شود).
- با همین روش می‌توان اطلاعات را به مرورگر یا دستگاه دیگر منتقل کرد.

## محدودیت‌های ذخیره‌سازی محلی
- اطلاعات مختص پروفایل همان مرورگر است و بین دستگاه‌ها همگام نمی‌شود.
- پاک‌کردن اطلاعات سایت/مرورگر یا حالت ناشناس (Private)، داده‌ها را از بین می‌برد؛ **منظم پشتیبان بگیرید**.
- برنامه قفل ورود یا احراز هویت سروری ندارد و امنیت آن همان امنیت دسترسی به دستگاه شماست.
- خروجی PNG/JPG/PDF در Chrome، Edge و Firefox آزمایش‌شده است؛ اگر در مرورگری کار نکرد، از «چاپ ← ذخیره به‌صورت PDF» استفاده کنید.
